<threat_model>
Threats covered by this plan:
- T-03-01 high: stale or poisoned lookup data is presented as fresh. Mitigation: cache records observed_at/expires_at and stale replies must be labeled by orchestration.
- T-03-02 high: worker subprocess hangs indefinitely. Mitigation: subprocess execution uses context timeouts.
- T-03-03 medium: worker logs corrupt JSON output. Mitigation: stdout must parse as one JSON response; stderr is not parsed as data.
- T-03-04 medium: credentials or secrets stored in cache. Mitigation: cache schema stores lookup result fields only, not env vars or tokens.
</threat_model>
